ЧАСТЬ 1. ТЕОРИЯ

1.1. Линейное уравнение: что это такое

Определение. Линейное уравнение с одной переменной — это уравнение вида:

\(ax = b\)

где \(a\) и \(b\) — заданные числа, \(x\) — неизвестное.

Почему «линейное»? Потому что \(x\) входит только в первой степени. Если нарисовать график \(y = ax - b\), это будет прямая линия.

УсловиеЧто происходитСколько решений
\(a \ne 0\)\(x = \frac{b}{a}\) — единственное решениеОдно
\(a = 0\), \(b = 0\)\(0 \cdot x = 0\) — верно при любом \(x\)Бесконечно много
\(a = 0\), \(b \ne 0\)\(0 \cdot x = b\) — противоречиеНет решений
⚠️ Типичная ошибка: Забывать про случаи \(a = 0\). На олимпиаде это особенно важно в задачах с параметром!

Пример 1. Реши уравнение \(3x - 7 = 2x + 5\).

\(3x - 2x = 5 + 7\)

\(x = 12\)

Проверка: \(3 \cdot 12 - 7 = 29\) и \(2 \cdot 12 + 5 = 29\) ✓

1.2. Главные правила работы с уравнениями

Уравнение — это весы. Что делаешь с одной стороной — делай и с другой.

Правило 1. Можно прибавить (или вычесть) одно и то же число к обеим частям

\(A = B\) ⇔ \(A + c = B + c\)

Зачем: чтобы «перенести» слагаемое на другую сторону.

\(3x + 5 = 11\) ⇒ \(3x = 11 - 5 = 6\) ⇒ \(x = 2\)

Правило 2. Можно умножить (или разделить) обе части на число \(\ne 0\)

\(A = B\) ⇔ \(A \cdot c = B \cdot c\) (при \(c \ne 0\))

\(\frac{x}{3} = 7\) ⇒ \(x = 7 \cdot 3 = 21\)

⚠️ Критическое замечание: делить на ноль нельзя! Это не просто правило — это фундаментальный запрет. Выражение \(\frac{a}{0}\) не определено.

Правило 3. Перенос слагаемого со сменой знака

\(a + b = c\) ⇔ \(a = c - b\)

Мнемоника: «Перелетел через знак \(=\) — поменял знак».

1.3. Уравнения, которые «притворяются» сложными

Многие уравнения выглядят страшно, но после упрощения становятся линейными.

Уравнения с дробями

Пример 2. Реши: \(\frac{2x + 1}{3} - \frac{x - 2}{4} = 1\)

Шаг 1. НОК(3, 4) = 12. Умножаем обе части на 12:

\(4(2x + 1) - 3(x - 2) = 12\)

Шаг 2. Раскрываем скобки:

\(8x + 4 - 3x + 6 = 12\)

\(5x + 10 = 12\)

\(5x = 2\)

\(x = \frac{2}{5}\)

Проверка: \(\frac{\frac{9}{5}}{3} - \frac{-\frac{8}{5}}{4} = \frac{3}{5} + \frac{2}{5} = 1\) ✓

⚠️ Типичные ошибки:
  • Забыть умножить каждый член на НОК (особенно свободный член справа!)
  • Неправильно раскрыть скобки: \(-3(x - 2) = -3x + 6\), а не \(-3x - 6\)!

Уравнения со скобками

Пример 3. Реши: \(5(x - 3) - 2(3x + 1) = x - 4\)

\(5x - 15 - 6x - 2 = x - 4\)

\(-x - 17 = x - 4\)

\(-2x = 13\)

\(x = -\frac{13}{2}\)

1.4. Линейные неравенства: главные отличия от уравнений

Определение. Линейное неравенство — выражение вида \(ax + b > 0\) (или \(\ge, <, \le\)).

Решить неравенство — найти множество всех \(x\), при которых оно верно. Ответ — это промежуток.

Правила работы с неравенствами

Правило 1. Прибавление/вычитание — знак НЕ меняется.

Если \(A > B\), то \(A + c > B + c\) для любого \(c\).

Правило 2. Умножение/деление на положительное число — знак НЕ меняется.

Если \(A > B\) и \(c > 0\), то \(Ac > Bc\).

⚠️ Правило 3. САМОЕ ВАЖНОЕ!
Умножение/деление на отрицательное число — знак ПЕРЕВОРАЧИВАЕТСЯ!
Если \(A > B\) и \(c < 0\), то \(Ac < Bc\).
💡 Почему переворачивается? Простой пример: \(3 > 2\). Умножим на \((-1)\): \(-3 < -2\). На числовой прямой: умножение на отрицательное число «отражает» все точки через ноль, и порядок меняется.

Пример 4. Реши: \(-3x + 7 > 1\).

\(-3x > -6\)

Делим на \((-3)\) — ПЕРЕВОРАЧИВАЕМ знак!

\(x < 2\)

Ответ: \(x \in (-\infty, 2)\).

Проверка: \(x = 1\): \(-3 + 7 = 4 > 1\) ✓. \(x = 3\): \(-9 + 7 = -2 > 1\)? Нет! ✓ (не должно подходить).

1.5. Системы и совокупности неравенств

Система неравенств (И)

Система — когда оба неравенства выполняются одновременно.

Пример. \(\begin{cases} 2x - 1 > 3 \\ x + 4 \le 10 \end{cases}\)

Первое: \(2x > 4\) ⇒ \(x > 2\).

Второе: \(x \le 6\).

Ответ: пересечение — \(x \in (2,\; 6]\).

Числовая прямая:
─────────(2════════════6]───────
         x > 2    x ≤ 6

Совокупность неравенств (ИЛИ)

Совокупность — достаточно выполнения хотя бы одного неравенства.

Ответ: объединение промежутков.

Запомни обозначения:
\(\begin{cases} \ldots \\ \ldots \end{cases}\) = фигурная скобка = система = И = пересечение
\(\left[\begin{array}{l} \ldots \\ \ldots \end{array}\right.\) = квадратная скобка = совокупность = ИЛИ = объединение

1.6. Строгие и нестрогие неравенства

СимволНазваниеГраничная точка
\(>\)СтрогоеНе входит — пустой кружок ○
\(\ge\)НестрогоеВходит — закрашенный кружок ●
\(<\)СтрогоеНе входит — пустой кружок ○
\(\le\)НестрогоеВходит — закрашенный кружок ●
Запись интервалов:
  • \((a, b)\) — открытый: \(a < x < b\) (концы не входят)
  • \([a, b]\) — замкнутый: \(a \le x \le b\) (концы входят)
  • \((a, b]\) — полуоткрытый: \(a < x \le b\)
  • \((-\infty, a)\) — луч: \(x < a\). Бесконечность всегда с круглой скобкой!

1.7. Уравнения с модулем (линейные)

Базовое уравнение: \(|f(x)| = a\)

\(|f(x)| = a\) (при \(a > 0\)) ⇔ \(f(x) = a\) или \(f(x) = -a\)

\(|f(x)| = 0\) ⇔ \(f(x) = 0\)

\(|f(x)| = a\) (при \(a < 0\)) ⇒ нет решений (модуль неотрицателен!)

Пример 5. Реши: \(|2x - 5| = 3\).

  • \(2x - 5 = 3\) ⇒ \(x = 4\)
  • \(2x - 5 = -3\) ⇒ \(x = 1\)

Ответ: \(x \in \{1,\; 4\}\).

Уравнение \(|f(x)| = |g(x)|\)

\(|f(x)| = |g(x)|\) ⇔ \(f(x) = g(x)\) или \(f(x) = -g(x)\)

Почему? Если модули равны, то сами числа либо равны, либо противоположны.

Пример 6. Реши: \(|3x - 1| = |x + 5|\).

  • Случай 1: \(3x - 1 = x + 5\) ⇒ \(2x = 6\) ⇒ \(x = 3\)
  • Случай 2: \(3x - 1 = -(x + 5)\) ⇒ \(4x = -4\) ⇒ \(x = -1\)

Ответ: \(x \in \{-1,\; 3\}\).

1.8. Неравенства с модулем (линейные)

\(|f(x)| < a\) — «зажат внутри»

\(|f(x)| < a\) (при \(a > 0\)) ⇔ \(-a < f(x) < a\)

Геометрический смысл: расстояние от \(f(x)\) до нуля меньше \(a\), значит \(f(x)\) лежит в интервале \((-a,\; a)\).

Пример 7. Реши: \(|2x - 1| < 5\).

\(-5 < 2x - 1 < 5\)

\(-4 < 2x < 6\)

\(-2 < x < 3\)

Ответ: \(x \in (-2,\; 3)\).

\(|f(x)| > a\) — «убежал наружу»

\(|f(x)| > a\) (при \(a > 0\)) ⇔ \(f(x) > a\) или \(f(x) < -a\)

Геометрический смысл: расстояние от \(f(x)\) до нуля больше \(a\), значит \(f(x)\) лежит за пределами интервала \((-a,\; a)\).

Пример 8. Реши: \(|3x + 2| \ge 7\).

  • \(3x + 2 \ge 7\) ⇒ \(x \ge \frac{5}{3}\)
  • \(3x + 2 \le -7\) ⇒ \(x \le -3\)

Ответ: \(x \in (-\infty,\; -3] \cup [\frac{5}{3},\; +\infty)\).

\(|f(x)| < a\) → «Зажат внутри»: \(-a < f(x) < a\) — один кусок
\(|f(x)| > a\) → «Убежал наружу»: \(f(x) < -a\) ИЛИ \(f(x) > a\) — два куска

1.9. Линейные уравнения с параметром

Что такое параметр? Это буква (обычно \(a, b, m, k\)), которая играет роль «заданного числа», но мы не знаем, какое именно. Нужно решить уравнение для всех возможных значений параметра.

Пример 9. Реши в зависимости от параметра \(a\): \(ax = a^2 - 1\).

Случай 1: \(a \ne 0\).

\(x = \frac{a^2 - 1}{a} = \frac{(a-1)(a+1)}{a} = a - \frac{1}{a}\)

Случай 2: \(a = 0\).

\(0 \cdot x = -1\) ⇒ \(0 = -1\) — противоречие. Нет решений.

Ответ: при \(a \ne 0\): \(x = \frac{a^2 - 1}{a}\); при \(a = 0\): решений нет.

Пример 10. При каких \(a\) уравнение \((a - 2)x = a^2 - 4\) имеет бесконечно много решений?

\((a - 2)x = (a - 2)(a + 2)\)

Бесконечно много решений при \(a - 2 = 0\) и правая часть тоже \(= 0\):

\(a = 2\): \(0 \cdot x = 0\) — верно при любом \(x\).

При \(a \ne 2\): \(x = a + 2\) — единственное решение.

1.10. Неравенства с параметром

Пример 11. Реши \(ax > 1\) в зависимости от \(a\).

Случай 1: \(a > 0\). Делим на \(a\) (знак не меняется): \(x > \frac{1}{a}\).

Случай 2: \(a < 0\). Делим на \(a\) (знак переворачивается!): \(x < \frac{1}{a}\).

Случай 3: \(a = 0\). \(0 > 1\) — ложь. Нет решений.

1.11. Метод интервалов для линейных выражений с модулем

Алгоритм (когда несколько модулей):

  1. Найди критические точки — значения \(x\), где выражения под модулями обращаются в ноль.
  2. Эти точки разбивают числовую прямую на интервалы.
  3. На каждом интервале раскрой модули (определи знак каждого выражения).
  4. Реши уравнение/неравенство на каждом интервале без модулей.
  5. Пересеки решение с интервалом (не забудь!).
  6. Объедини решения со всех интервалов.

Пример 12. Реши: \(|x - 1| + |x + 3| = 6\).

Критические точки: \(x = 1\) и \(x = -3\). Три интервала:

Интервал\(|x - 1|\)\(|x + 3|\)Уравнение
\(x < -3\)\(1 - x\)\(-x - 3\)\(-2x - 2 = 6\)
\(-3 \le x < 1\)\(1 - x\)\(x + 3\)\(4 = 6\)
\(x \ge 1\)\(x - 1\)\(x + 3\)\(2x + 2 = 6\)

Интервал 1: \(-2x - 2 = 6\) ⇒ \(x = -4\). Проверка: \(-4 < -3\) ✓

Интервал 2: \(4 = 6\) — противоречие.

Интервал 3: \(2x + 2 = 6\) ⇒ \(x = 2\). Проверка: \(2 \ge 1\) ✓

Ответ: \(x \in \{-4,\; 2\}\).

💡 Геометрический смысл: \(|x - 1| + |x + 3|\) — сумма расстояний от \(x\) до точек 1 и −3. Расстояние между ними = 4. При \(x\) между ними сумма всегда = 4. Нам нужна сумма 6, значит \(x\) «убежал» за пределы на \(\frac{6-4}{2} = 1\) с каждой стороны.

ЧАСТЬ 2. ОЛИМПИАДНЫЕ ПРИЁМЫ

Приём 1. Целые решения — перебор делителей

Когда дробь с \(x\) должна быть целым числом — приравняй знаменатель к делителям числителя.

Пример. Найди все целые \(x\): \(\frac{5}{x - 3}\) — целое число.

\((x - 3) \mid 5\) ⇒ \(x - 3 \in \{-5, -1, 1, 5\}\) ⇒ \(x \in \{-2, 2, 4, 8\}\).

Приём 2. Уравнение с параметром — разбор случаев

Если коэффициент при \(x\) содержит параметр — обязательно рассмотри, когда он равен нулю!

Алгоритм:

  1. Приведи к виду \(f(a) \cdot x = g(a)\).
  2. \(f(a) \ne 0\) ⇒ \(x = \frac{g(a)}{f(a)}\).
  3. \(f(a) = 0\): если \(g(a) = 0\) — бесконечно много решений; если \(g(a) \ne 0\) — нет решений.

Приём 3. Собери \(x\) в одну сторону

Перенеси все члены с \(x\) влево, все числа вправо. Потом делай с учётом знака!

Пример. Реши: \(3x - 7 < 5x + 1\).

\(3x - 5x < 1 + 7\) ⇒ \(-2x < 8\) ⇒ \(x > -4\) (делим на \(-2\), знак переворачивается!).

Приём 4. Системы — метод числовой прямой

Реши каждое неравенство отдельно. Нарисуй на числовой прямой. Найди пересечение (система) или объединение (совокупность).

Приём 5. Модуль как расстояние

\(|x - a|\) = расстояние от точки \(x\) до точки \(a\) на числовой прямой.

  • \(|x - 3| < 5\) ⇒ расстояние от \(x\) до 3 меньше 5 ⇒ \(x \in (-2, 8)\)
  • \(|x - 3| > 5\) ⇒ расстояние больше 5 ⇒ \(x \in (-\infty, -2) \cup (8, +\infty)\)
  • \(|x - 3| = 5\) ⇒ \(x \in \{-2, 8\}\)
Для суммы модулей: \(|x - a| + |x - b| = c\) — задача о точках, сумма расстояний до которых равна \(c\). Если \(c = |a - b|\), то \(x\) между \(a\) и \(b\). Если \(c > |a - b|\), решение — две точки за пределами отрезка.

Приём 6. Хитрая группировка

Пример. Реши: \(|x - 1| + |x - 2| + |x - 3| = 2\).

Хитрость: \(|x - 1| + |x - 3| \ge |(x-1) - (x-3)| = 2\) (неравенство треугольника!). Равенство при \(1 \le x \le 3\).

Если \(|x - 1| + |x - 3| = 2\), то \(|x - 2| = 0\), т.е. \(x = 2\).

Ответ: \(x = 2\).

Приём 7. Замена переменной

Если выражение повторяется — замени его новой переменной.

Пример. Реши: \(|3x + 1| = 2|3x + 1| - 5\).

Пусть \(t = |3x + 1|\), тогда \(t \ge 0\) и \(t = 2t - 5\) ⇒ \(t = 5\).

Значит \(|3x + 1| = 5\): \(x = \frac{4}{3}\) или \(x = -2\).

Навигатор: как выбрать приём

Задача на линейные уравнения/неравенства → спроси себя:

1. Есть параметр?
   → Разбор случаев: коэффициент = 0 или ≠ 0 (Приём 2)

2. Есть модуль?
   → Один модуль: формулы |f| = a, |f| < a, |f| > a
   → Несколько модулей: метод интервалов (1.11)
   → Сумма модулей: геометрическая интерпретация (Приём 5)

3. Нужно найти ЦЕЛЫЕ решения?
   → Перебор делителей (Приём 1)

4. Система неравенств?
   → Реши каждое, нарисуй, пересеки (Приём 4)

5. Просто уравнение/неравенство?
   → НОК для дробей, раскрой скобки (1.3, Приём 3)

ЧАСТЬ 4. РЕШЕНИЯ

Решение 1.1

Реши: \(\frac{x + 1}{2} - \frac{x - 3}{5} = 1\).

НОК(2, 5) = 10. Умножаем обе части на 10:

\(5(x + 1) - 2(x - 3) = 10\)

\(5x + 5 - 2x + 6 = 10\)

Решение 2.3

Реши: \(|2x - 5| \le |x + 1|\).

Метод: оба модуля неотрицательны, возведём в квадрат:

\((2x - 5)^2 \le (x + 1)^2\)

\((2x - 5)^2 - (x + 1)^2 \le 0\)

Формула \(A^2 - B^2 = (A-B)(A+B)\):

\(\big((2x-5) - (x+1)\big)\big((2x-5) + (x+1)\big) \le 0\)

\((x - 6)(3x - 4) \le 0\)

Нули: \(x = \frac{4}{3}\) и \(x = 6\). Произведение \(\le 0\) между корнями:

Ответ: \(x \in \left[\frac{4}{3},\; 6\right]\).

Проверка: \(x = 2\): \(|{-1}| \le |3|\), \(1 \le 3\) ✓. \(x = 0\): \(5 \le 1\)? ✗ (правильно).

Решение 2.4

Реши: \((a + 1)x = a^2 - 1\).

Заметим: \(a^2 - 1 = (a+1)(a-1)\).

Случай 1: \(a \ne -1\). \(x = \frac{(a+1)(a-1)}{a+1} = a - 1\). Одно решение.

Случай 2: \(a = -1\). \(0 \cdot x = 0\) — верно при любом \(x\). Бесконечно много решений.

Решение 3.1

Реши: \(|x - 1| + |x - 5| = |2x - 6|\).

Наблюдение: \(|2x - 6| = 2|x - 3|\), а также \((x-1) + (x-5) = 2x - 6\).

Значит: \(|x - 1| + |x - 5| = |(x-1) + (x-5)|\).

По неравенству треугольника: \(|A| + |B| \ge |A + B|\), равенство при \(A\) и \(B\) одного знака.

Здесь \(A = x - 1\), \(B = x - 5\). Одного знака, когда:

  • Оба \(\ge 0\): \(x \ge 5\)
  • Оба \(\le 0\): \(x \le 1\)

Ответ: \(x \in (-\infty, 1] \cup [5, +\infty)\).

Проверка: \(x = 0\): \(1 + 5 = 6\) и \(|{-6}| = 6\) ✓. \(x = 3\): \(2 + 2 = 4\) и \(|0| = 0\), \(4 \ne 0\) ✗ (правильно).

Решение 3.2

Найди все \(a\): \(ax + 1 > a + x\) при всех \(x > 0\).

Преобразуем: \(x(a-1) > a - 1\), т.е. \((a-1)(x-1) > 0\).

Случай 1: \(a > 1\). Нужно \(x > 1\) — не для всех \(x > 0\). Не подходит.

Случай 2: \(a = 1\). \(0 > 0\) — ложь. Не подходит.

Случай 3: \(a < 1\). Нужно \(x < 1\) — не для всех \(x > 0\). Не подходит.

Ответ: нет таких \(a\) (пустое множество).

Решение 3.3

Система в целых числах: \(\begin{cases} \frac{x}{3} - \frac{x-1}{6} > 0 \\ \frac{2x+1}{4} \le 2 \end{cases}\)

Первое: НОК(3, 6) = 6: \(\frac{2x - (x-1)}{6} > 0\) ⇒ \(x + 1 > 0\) ⇒ \(x > -1\).

Второе: \(2x + 1 \le 8\) ⇒ \(x \le 3.5\).

Целые: \(x \in \{0, 1, 2, 3\}\).

Решение 3.4

Минимум \(|x + 1| + |x - 3| + |x - 7|\).

Три точки: \(-1, 3, 7\). Медиана — средняя точка: \(3\).

При \(x = 3\): \(4 + 0 + 4 = 8\).

Доказательство:

  • \(|x + 1| + |x - 7| \ge |(-1) - 7| = 8\) (неравенство треугольника). Равенство при \(-1 \le x \le 7\).
  • \(|x - 3| \ge 0\). Равенство при \(x = 3\).

Сумма \(\ge 8 + 0 = 8\). Равенство при \(x = 3\).

Ответ: минимум = 8, при \(x = 3\).

Решение 4.1

Все пары целых \((x, y)\): \(3x + 5y = 1\).

Шаг 1. Подбираем одно решение: \(x = 2, y = -1\) ⇒ \(6 - 5 = 1\) ✓.

Шаг 2. Вычитаем: \(3(x - 2) + 5(y + 1) = 0\), т.е. \(3(x-2) = -5(y+1)\).

Так как \(\gcd(3, 5) = 1\), то \(5 \mid (x - 2)\), т.е. \(x - 2 = 5t\).

\(x = 2 + 5t\), \(y = -1 - 3t\), где \(t \in \mathbb{Z}\).

Примеры:

  • \(t = 0\): \((2, -1)\) ⇒ \(6 - 5 = 1\) ✓
  • \(t = 1\): \((7, -4)\) ⇒ \(21 - 20 = 1\) ✓
  • \(t = -1\): \((-3, 2)\) ⇒ \(-9 + 10 = 1\) ✓

Решение 4.2

При каких \(a\) система \(\begin{cases} x > a \\ ax > 1 \end{cases}\) имеет ровно одно целое решение?

При \(a > 0\): система \(x > \max(a, \frac{1}{a})\) — бесконечно много целых. Не подходит.

При \(a = 0\): второе неравенство \(0 > 1\) — ложь. Не подходит.

При \(a < 0\): делим второе на \(a < 0\) (переворот!): \(x < \frac{1}{a}\). Система: \(a < x < \frac{1}{a}\).

При \(-1 < a < 0\): \(\frac{1}{a} < -1 < a\) — пустой интервал.

При \(a = -1\): \((-1, -1)\) — пустой.

При \(a < -1\): интервал \((a, \frac{1}{a})\), где \(a < -1\) и \(-1 < \frac{1}{a} < 0\). Единственное целое в этом интервале — число \(-1\).

Целое \(-2\) попадает, если \(a < -2\) — лишнее решение!

Ответ: \(a \in [-2, -1)\).

Проверка: \(a = -2\): \((-2, -0.5)\), целые: \(\{-1\}\) ✓. \(a = -1.5\): \((-1.5, -0.\overline{6})\), целые: \(\{-1\}\) ✓.

Решение 4.3

\(|x - a| + |x - b| + |x - c| = b - a\) при \(a < b < c\).

Минимум левой части достигается при \(x = b\) (медиана) и равен:

\(|b - a| + 0 + |b - c| = (b - a) + (c - b) = c - a\).

Уравнение разрешимо ⇔ \(b - a \ge c - a\), т.е. \(b \ge c\). Но по условию \(b < c\) — противоречие.

Значит, при строгом \(a < b < c\) уравнение не имеет решений, так как минимум левой части равен \(c - a > b - a\).

Условие \(c \le 2b - a\) эквивалентно \(c - a \le 2(b - a)\) — это необходимое условие для модифицированных вариантов задачи.

Решение 4.4

Для каких целых \(n\): \(\frac{n + 3}{n - 1} \le 2\)?

⚠️ НЕЛЬЗЯ умножать на \((n - 1)\) — знак неизвестен!

Чек-лист: главные формулы и приёмы

🔢 Линейные уравнения

  • \(ax = b\): при \(a \ne 0\) → \(x = b/a\); при \(a = 0, b = 0\) → любое \(x\); при \(a = 0, b \ne 0\) → нет решений
  • Дроби: умножь на НОК знаменателей
  • Скобки: раскрой аккуратно (минус перед скобкой!)

🔢 Линейные неравенства

  • Всё как с уравнениями, НО: умножение/деление на отрицательное → ПЕРЕВОРОТ знака!
  • Система (И) → пересечение
  • Совокупность (ИЛИ) → объединение

🔢 Модуль

  • \(|f| = a\) → \(f = a\) или \(f = -a\)
  • \(|f| < a\) → \(-a < f < a\) (внутри)
  • \(|f| > a\) → \(f > a\) или \(f < -a\) (снаружи)
  • \(|f| = |g|\) → \(f = g\) или \(f = -g\)
  • Несколько модулей → метод интервалов

🔢 Параметры

  • Коэффициент при \(x\) содержит параметр? Обязательно рассмотри: = 0, > 0, < 0
  • Неравенство с параметром в знаменателе? НЕ УМНОЖАЙ! Перенеси, метод интервалов.

🔢 Олимпиадные фишки

  • Дробь целая → деление с остатком → перебор делителей
  • \(|A| + |B| \ge |A + B|\) (равенство при одинаковых знаках)
  • \(\sum |x - a_i|\) минимальна в медианной точке
  • \(3x + 5y = 1\): один корень + общая формула через НОД
