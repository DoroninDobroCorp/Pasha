# 🎮 Tower Defense: Оптимальная точка патрулирования дрона

## 💼 Где это используется?

Такие задачи постоянно встречаются в индустрии:

- **Яндекс.Еда / Delivery Club** — где разместить "тёмную кухню", чтобы курьеры быстрее доезжали до клиентов (учитывая, что из центра заказов больше)?
- **AWS / Cloudflare** — где поставить сервер, чтобы пинг до пользователей был минимальным?
- **Сети магазинов** — где построить склад для оптимальной доставки?
- **Gamedev** — как раз наш случай с дроном!

Все они сводятся к одному: **минимизация взвешенной суммы расстояний**.  
А расстояние — это модуль разности координат: `|a - b|`.

На уроке мы разбирали медиану — она минимизирует сумму расстояний.  
Здесь то же самое, но с **весами** (приоритетами). Справишься! 💪

---

## Легенда

Ты разрабатываешь AI для игры Tower Defense. В твоей игре есть **ремонтный дрон**, 
который восстанавливает повреждённые башни между волнами врагов.

После очередной волны несколько башен получили урон. Дрон должен выбрать 
**точку патрулирования** — позицию, из которой он сможет максимально эффективно 
обслуживать все повреждённые башни.

## Механика

- Башни расположены на **числовой прямой** (одномерная карта — траншея, мост, стена)
- У каждой башни есть координата `x` и текущее здоровье `health` (от 1 до 100)
- **Приоритет башни** = `100 - health` (чем меньше здоровья, тем срочнее ремонт)
- Дрон летит к башне за время, равное расстоянию: `|drone_x - tower_x|`

## Задача

Найди координату точки патрулирования `patrol_x`, которая минимизирует 
**взвешенное суммарное время** полёта до всех башен:

```
S = Σ priority[i] × |patrol_x - tower_x[i]|
  = Σ (100 - health[i]) × |patrol_x - tower_x[i]|
```

## Формат входных данных

Первая строка: число башен `n` (1 ≤ n ≤ 100000)

Следующие `n` строк: `x health` — координата и здоровье башни
- Координаты: целые числа от -10⁹ до 10⁹
- Здоровье: целые числа от 1 до 99

## Формат выходных данных

Два числа через пробел:
1. Оптимальная координата патрулирования (целое число)
2. Минимальное взвешенное время (может быть большим!)

Если оптимальных точек несколько — выведи любую из них.

## Примеры

### Пример 1
```
Вход:
3
10 80
25 30
40 90

Выход:
25 450
```

**Объяснение:**
- Башня в x=10: приоритет = 100-80 = 20
- Башня в x=25: приоритет = 100-30 = 70  ← самая повреждённая!
- Башня в x=40: приоритет = 100-90 = 10

Если дрон в точке 25:
- До башни 10: 20 × |25-10| = 20 × 15 = 300
- До башни 25: 70 × |25-25| = 70 × 0 = 0
- До башни 40: 10 × |25-40| = 10 × 15 = 150
- **Итого: 450**

Проверь сам: что будет, если дрон встанет в x=10 или x=40?

### Пример 2
```
Вход:
4
10 80
25 30
40 90
60 20

Выход:
25 3250
```

Разбор:
- x=10: приоритет 20, x=25: приоритет 70, x=40: приоритет 10, x=60: приоритет 80
- Самая критичная башня в x=60 (HP=20), но x=25 всё равно лучше из-за позиции

### Пример 3 (ловушка!)
```
Вход:
3
0 99
50 99
100 99

Выход:
50 100
```

Все башни с одинаковым приоритетом → классическая задача о медиане.

### Пример 4 (крайний случай)
```
Вход:
2
0 99
1000000000 1

Выход:
1000000000 1000000000
```

Одна башня почти мертва (приоритет 99), другая почти цела (приоритет 1).
Дрон должен стоять у критичной башни! Проверь: если бы дрон стоял в 0,
расстояние было бы 99 × 10⁹ = 99 млрд — намного хуже!

## Подсказки (открывай по одной!)

<details>
<summary>Подсказка 1: Наивное решение</summary>

Можно перебрать все координаты башен как кандидатов на точку патрулирования
и для каждой посчитать сумму. Сложность O(n²) — пройдёт для n ≤ 1000.

</details>

<details>
<summary>Подсказка 2: Математический инсайт</summary>

Функция `f(x) = Σ wᵢ × |x - aᵢ|` — это **кусочно-линейная** функция.
Её минимум достигается в одной из точек `aᵢ` (координат башен).
Но в какой именно?

</details>

<details>
<summary>Подсказка 3: Взвешенная медиана</summary>

Ответ — это **взвешенная медиана**: точка, где сумма весов слева ≥ половины 
общего веса, и сумма весов справа тоже ≥ половины.

Алгоритм:
1. Отсортируй башни по координате
2. Накапливай сумму весов слева направо
3. Найди первую точку, где накопленная сумма ≥ total_weight / 2

</details>

<details>
<summary>Подсказка 4: Эффективное решение</summary>

Сложность O(n log n) из-за сортировки.
Можно даже O(n) через алгоритм поиска k-й порядковой статистики, 
но для олимпиады O(n log n) достаточно.

</details>

## Дополнительные задания ⭐

### Уровень 2: Два дрона
Теперь у тебя **два** ремонтных дрона. Каждая башня будет обслуживаться 
ближайшим дроном. Найди оптимальные позиции для обоих.

### Уровень 3: Двумерная карта
Башни теперь на плоскости (x, y). Как изменится решение?
(Спойлер: координаты можно оптимизировать независимо!)

### Уровень 4: Дрон с ограниченным радиусом
Дрон может долететь максимум на расстояние `R`. Башни дальше `R` получают 
штраф за недоступность. Как это учесть?
